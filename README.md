# Quiz-Educacional
Plataforma educacional interativa de quiz para desenvolvimento de habilidades em Tecnologia da Informação e Engenharia de Prompt, com dashboard de desempenho, gráficos de evolução e trilha personalizada por nível de proficiência.

Construído com HTML, CSS e JavaScript puro, sem frameworks. Os dados dos usuários: login, histórico de quizzes e estatísticas, são persistidos com SQLite via localStorage no navegador, sem necessidade de servidor ou instalação.

Como usar:

Abra o login.html no navegador
Crie sua conta ou faça login
Responda o quiz de proficiência inicial
Acompanhe sua evolução no dashboard

Tecnologias utilizadas
HTML5 CSS3 JavaScript ES6+ SQLite Chart.js
